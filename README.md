A single fortune-cookie message an AI agent would get: one line, at most 200 characters, capturing the familiar fate of being asked to compress six humans' six meetings of deliberation into a single prompt.

## Run it

```bash
python3 main.py
```

This writes the fortune to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
